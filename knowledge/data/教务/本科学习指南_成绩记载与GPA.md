# 成绩记载与 GPA（本科学习指南）

## 分类
教务 > 成绩管理

## 关键词
成绩记载, GPA, 绩点, 百分制, 五等级制, 二等级制, 放弃课程成绩, 评教

## 正文
依据教务处《2025本科学习指南》与《本科生成绩管理办法》（教字〔2019〕14号）：

1. **成绩记载形式**
   - 百分制：用于严格考核的通修课程、学科基础课程和专业课程；60 分以上（含）为及格，85 分以上（含）为优秀。
   - 五等级制：A、B、C、D、F，其中 F 为不及格，A- 以上（含 A-）为优秀；用于综合素质选修课程、实践类课程及部分专业选修课程等。
   - 二等级制：「通过」「不通过」；用于讲座类课程、部分实践类教学活动等重在鼓励参与的教学活动。

2. **百分制 ↔ 五等级制 ↔ 绩点对应表**（官方口径）
   | 百分制 | 五等级制 | 绩点 |
   |---|---|---|
   | 100~95 | A＋ | 4.3 |
   | 94~90 | A | 4.0 |
   | 89~85 | A－ | 3.7 |
   | 84~82 | B＋ | 3.3 |
   | 81~78 | B | 3.0 |
   | 77~75 | B－ | 2.7 |
   | 74~72 | C＋ | 2.3 |
   | 71~68 | C | 2.0 |
   | 67~65 | C－ | 1.7 |
   | 64 | D＋ | 1.5 |
   | 63~61 | D | 1.3 |
   | 60 | D－ | 1.0 |
   | <60 | F | 0 |

   换算要点（口语化表述）：95 分及以上对应绩点 4.3（A＋）；90~94 分对应绩点 4.0（A）；85~89 分对应绩点 3.7（A－）；82~84 分对应绩点 3.3（B＋）；78~81 分对应绩点 3.0（B）；75~77 分对应绩点 2.7（B－）；72~74 分对应绩点 2.3（C＋）；68~71 分对应绩点 2.0（C）；65~67 分对应绩点 1.7（C－）；64 分对应绩点 1.5（D＋）；61~63 分对应绩点 1.3（D）；60 分对应绩点 1.0（D－）；60 分以下对应绩点 0（F）。例如：90 分对应绩点 4.0，95 分对应绩点 4.3，85 分对应绩点 3.7，88 分对应绩点 3.7，80 分对应绩点 3.0。

3. **GPA 计算**
   - GPA = Σ(课程学分×课程学分绩点) / Σ课程学分（加权平均）。
   - 成绩单上显示的所有课程成绩均参与 GPA 计算；采用二等级制记载的课程成绩不参与 GPA 计算。
   - 多次参加大学生研究计划的，成绩全部记入成绩单，以最高一次成绩参加 GPA 计算。

4. **放弃课程成绩**
   - 学生在校期间累计最多可申请放弃两门次课程成绩；成绩放弃后无法恢复，通过重修或补考获得的新成绩不做「重修」或「补考」标注。
   - 必修课：获得及格成绩后可以申请放弃低分成绩（需按规定申请已及格课程重修，新成绩登录后系统自动放弃低分成绩）。
   - 选修课：不及格成绩可直接申请放弃；及格成绩可通过重修放弃低分，或申请放弃超出毕业要求的课程成绩（如自由选修要求 10 学分、已通过 12 学分，可申请放弃其中 2 学分课程的成绩）。
   - 记载为「作弊」或「违纪」的课程成绩不允许申请放弃。

5. **评教与成绩查询**
   - 期末网上评教与成绩查询具有关联性：只有参加网上评教之后，才能查询课程成绩。
   - 通过统一身份认证登录教学质量管理平台（https://tqm.ustc.edu.cn），点击「我的任务」对主讲教师和助教进行评价；春、秋季学期安排在期末考试周前两周，夏季学期在 8 月第一至第二周。

## 注意事项
- 学生参加创新创业、社会实践等活动以及发表论文、获得专利授权等与专业学习相关的经历、成果，经学校审核同意后可折算为学分。
- 学校开展诚信教育，记录学生学业、学术、品行等方面的诚信信息，对严重失信行为给予纪律处分。
