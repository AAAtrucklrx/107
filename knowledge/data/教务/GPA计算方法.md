# GPA 计算方法（科大4.3制）

## 分类
教务 > 学籍管理

## 关键词
GPA, 绩点, 4.3制, 计算方法, 百分制, 五等级制, 二等级制

## 正文
依据教务处《2025本科学习指南》与《本科生成绩管理办法》（教字〔2019〕14号）：

1. **计算公式**：GPA = Σ(课程学分 × 课程绩点) / Σ(课程学分)（加权平均）。

2. **官方分数-绩点对照表**（百分制 ↔ 五等级制 ↔ 绩点）：
   | 百分制 | 五等级制 | 绩点 |
   |---|---|---|
   | 100~95 | A＋ | 4.3 |
   | 94~90 | A | 4.0 |
   | 89~85 | A－ | 3.7 |
   | 84~82 | B＋ | 3.3 |
   | 81~78 | B | 3.0 |
   | 77~75 | B－ | 2.7 |
   | 74~72 | C＋ | 2.3 |
   | 71~68 | C | 2.0 |
   | 67~65 | C－ | 1.7 |
   | 64 | D＋ | 1.5 |
   | 63~61 | D | 1.3 |
   | 60 | D－ | 1.0 |
   | <60 | F | 0 |

   换算要点（与上表等价的口语化表述）：95 分及以上（100~95）对应绩点 4.3（A＋）；90~94 分对应绩点 4.0（A）；85~89 分对应绩点 3.7（A－）；82~84 分对应绩点 3.3（B＋）；78~81 分对应绩点 3.0（B）；75~77 分对应绩点 2.7（B－）；72~74 分对应绩点 2.3（C＋）；68~71 分对应绩点 2.0（C）；65~67 分对应绩点 1.7（C－）；64 分对应绩点 1.5（D＋）；61~63 分对应绩点 1.3（D）；60 分对应绩点 1.0（D－）；60 分以下对应绩点 0（F）。例如：90 分对应绩点 4.0，95 分对应绩点 4.3，85 分对应绩点 3.7，88 分对应绩点 3.7，80 分对应绩点 3.0。

3. **参与计算的课程**：成绩单上显示的所有课程成绩均参与 GPA 计算；采用二等级制（通过/不通过）记载的课程成绩不参与 GPA 计算。
   - 百分制成绩 60 分以上（含）为及格，85 分以上（含）为优秀；五等级制中 F 为不及格，A- 以上（含 A-）为优秀。
   - 学生在校期间多次参加大学生研究计划，成绩全部记入成绩单，以最高一次成绩参加 GPA 计算。

4. **成绩记载说明**
   - 补考或多次重修同一门不及格课程，成绩单只显示第一次考核成绩与通过后的成绩；因考核不及格而重修或补考通过的成绩分别标注「重修」或「补考」。
   - 旷考、作弊、违纪成绩显示「0」分，参与 GPA 计算；作弊、违纪成绩不允许申请放弃。

## 注意事项
- 各门课程最终成绩中优秀率（85 分及以上）不宜超过 40%。
- 成绩以综合教务系统记载为准；出国申请等如需绩点换算，请以接收方要求为准。
