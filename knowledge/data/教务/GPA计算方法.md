# GPA 计算方法（科大4.3制）

## 分类
教务 > 学籍管理

## 关键词
GPA, 绩点, 4.3制, 计算方法, 成绩

## 正文
1. 科大采用4.3制GPA
2. 计算公式：GPA = Σ(课程绩点 × 学分) / Σ(学分)
3. 分数-绩点对照表：
   - 95-100分 → 4.3
   - 90-94分 → 4.0
   - 85-89分 → 3.7
   - 82-84分 → 3.3
   - 78-81分 → 3.0
   - 75-77分 → 2.7
   - 72-74分 → 2.3
   - 68-71分 → 2.0
   - 64-67分 → 1.5
   - 60-63分 → 1.0
   - <60分 → 0
4. 等级制成绩：优秀=4.3, 良好=3.7, 中等=3.0, 及格=1.0
5. 不计入GPA的课程：体育课、通识选修（部分）

## 注意事项
- 重修课程取最高成绩计算GPA
- 保研GPA只计算前三年
- 出国GPA建议用WES认证换算
