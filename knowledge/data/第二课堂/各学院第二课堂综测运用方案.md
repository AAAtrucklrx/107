# 各学院第二课堂综测运用方案

## 分类
第二课堂 > 综合素质测评

## 关键词
综合素质测评, 综测, 评奖评优, 推免, 各学院, 门槛, 占比, GPA

## 正文
根据《中国科学技术大学本科生综合素质评价实施办法》附表"各学院第二课堂成绩单在学生综合素质测评中的运用情况"（截至 2026 年 8 月）：

| 学院 | 纳入学年评奖评优 | 推免是否要求 | 推免要求/方案 | 备注 |
| --- | --- | --- | --- | --- |
| 少年班学院 | 是（门槛） | 是 | 门槛：上一学年二课总学时不少于 60，且"美""劳"模块各不少于 10（模块总学时达毕业要求后不再特别要求）；考虑整个大学阶段时：二课总星级≥2 且"美""劳"模块总学时达到毕业要求。"美""劳"模块总学时达到 32 学时 | 25 年起执行 |
| 数学学院 | 是 | 否 | 门槛：每学年各模块至少 4 学时，总学时至少 20 | — |
| 物理学院 | 是（5%） | 是 | 门槛：第二课堂总学时不少于 72 | 23 级起执行 |
| 化材学院 | 是（4.4%） | 是 | 综测=第二课堂星级/25+GPA+科研潜质分 | 24 级起执行 |
| 工程学院 | 是（门槛） | 是 | 评价时段内二课成绩单每学年平均学时不少于 50 学时 | 24 年起执行 |
| 信息学院 | 是 | 是 | 门槛：累计每学年平均不低于 60 学时，单项不低于 12 学时；学籍转入学生自转入学院起计算 | 22 级起执行 |
| 计算机学院 | 是（4%） | 是 | 门槛：德、智、体、美四模块学时各不少于 50；劳模块按学时赋分（10-20 学时 0.2 分、20-40 学时 0.3 分、40-60 学时 0.4 分、60 学时及以上 0.5 分） | 25 年秋季起执行 |
| 人工智能与数据科学学院 | 是（门槛） | 否 | 综测得分=学习成绩+科研素养分+（班主任评定分+班级评定分+任职分+奖励分）×二课赋分系数；二课赋分系数=（各模块学时/15 之和）/5，某模块超 15 学时按 15 计 | — |
| 网安学院 | 是 | 是 | 门槛：总学时不少于 150 学时 | 评奖 26 年起执行，保研 23 级起执行 |
| 集成电路学院 | 是 | 是 | 门槛：平均每学年不少于 60 学时 | 23 级起执行 |
| 地空学院 | 是 | 是 | 综合成绩=学业成绩+其他；"其他"由学院另行细则，二课在百分制加权平均分上加分不超过 4 分 | 25 级起执行，细则详询学院 |
| 生医部 | 是（门槛） | 否 | 当年度二课学时不低于 40，单模块不低于 5 | — |
| 科技商学院、管理学院 | 是（门槛） | 是 | 门槛：上一学年不少于 60 学时，单个模块不少于 10 学时；推免按学院要求 | 23 年起执行 |
| 人文学院 | 是 | 是 | 各班级自行制定细则，二课活动时长在学业成绩加权平均分上加分不超过 1 分 | — |
| 环境学院 | 是（5%） | 是 | 综测得分=成绩分×82.5%+科研分×15%+前三学年二课星级×50% | — |
| 核学院 | 是（5%） | 是 | 综测得分=GPA×0.95+4.3/5×二课星级×0.05 | — |
| 未来技术学院 | 是（5%） | 是 | 门槛：第二课堂总学时不少于 72 | 25 级起执行 |

各学院评奖评优中的常见折算公式示例：
- 物理学院：综合素质评价分=GPA×0.95+4.3/5×第二课堂星级×0.05；对名额分配到学院的奖项（如"郭沫若奖学金""国家奖学金""宝钢奖学金"），获奖与否由评审委员会最终投票决定。
- 化材学院：综测=第二课堂星级/25+GPA。
- 环境学院：评奖评优综测=第二课堂星级×0.05×4.3/5+GPA×0.95。
- 计算机学院：每个模块超 40 学时计 0.8 分（满分 4 分）；30.5-40 学时计 0.64 分、20.5-30 学时计 0.48 分、10.5-20 学时计 0.32 分、0.5-10 学时计 0.16 分，单模块 0 学时不计分。
- 未来技术学院：与物理学院公式相同。

## 注意事项
- 原表注明：各学院综测方案会有调整，本表格仅供参考，请以学院文件为准。
- 本文档信息截至 2026 年 8 月（第二课堂用户指南 2026 版附表）。
