## 1. 前置准备

### 所需条件
- 一个 **GitHub 账号**（没有的话花 2 分钟注册一个）
- **Git**（版本控制工具）
- **Python 3.x**（项目开发语言）

## 2. 注册/登录 GitHub 账号

如果还没有 GitHub 账号，花 2 分钟注册一个：

1. 打开 https://github.com/signup
2. 输入邮箱、密码，设置用户名
3. 完成邮箱验证
4. **把你的 GitHub 用户名告诉项目负责人**（他会把你加为仓库协作者）

> 已有账号？直接登录就好，然后把 **用户名** 发给负责人。

## 3. 安装开发工具

### 3.1 安装 Git

Git 用于从 GitHub 拉取代码和提交你的修改。

```powershell
winget install Git.Git --accept-source-agreements --accept-package-agreements
```

安装后验证：
```powershell
git --version
```

### 3.2 安装 Python 3.x

从官网下载安装：https://www.python.org/downloads/

安装时记得勾选 **"Add Python to PATH"**。

安装后验证：
```powershell
python --version
```

### 3.3 配置 Git 用户信息

打开终端，配置你的 Git 用户名和邮箱（与 GitHub 账号一致）：

```powershell
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱"
```

### 3.4 安装代码编辑器

推荐使用 **VS Code**：https://code.visualstudio.com/

## 5. 配置 Python 开发环境

### 5.1 创建虚拟环境

每个项目单独创建虚拟环境，避免依赖冲突：

```powershell
# 进入项目目录
cd F:\107

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（每次开发前都要运行）
venv\Scripts\activate

# 安装依赖（后续有 requirements.txt 后再运行）
pip install -r requirements.txt
```

激活成功后，终端前面会出现 `(venv)` 字样。

### 5.2 VS Code 配置

用 VS Code 打开项目文件夹后，选择 Python 解释器：
- 按 `Ctrl+Shift+P` → 输入 `Python: Select Interpreter`
- 选择 `./venv/Scripts/python.exe`

## 6. 团队协作工作流程

### 6.1 日常开发流程

```
1. 拉取最新代码          → git pull
2. 创建功能分支          → git checkout -b feature/xxx
3. 编写代码              → 用编辑器写代码
4. 暂存修改              → git add .
5. 提交到本地            → git commit -m "描述你的改动"
6. 推送到 GitHub         → git push origin feature/xxx
7. 在 GitHub 上创建 PR   → 网页操作
8. 等待审查合并          → 项目负责人审查后合并到 main
```

### 6.2 完整示例

以开发"用户登录功能"为例：

```powershell
# 第 1 步：拉取最新代码
git pull

# 第 2 步：创建功能分支
git checkout -b feature/login-page

# 第 3 步：写代码（在编辑器中修改文件）

# 第 4 步：查看修改了哪些文件
git status

# 第 5 步：暂存所有修改
git add .

# 第 6 步：提交到本地仓库
git commit -m "[feat] 添加用户登录页面"

# 第 7 步：推送到 GitHub
git push origin feature/login-page

# 第 8 步：打开 GitHub 网页创建 Pull Request
```

### 6.3 分支命名规范

| 类型 | 格式 | 示例 |
|:---|:---|:---|
| 新功能 | `feature/xxx` | `feature/login-page` |
| 修复 Bug | `fix/xxx` | `fix/null-pointer` |
| 文档 | `docs/xxx` | `docs/api-guide` |
| 优化 | `refactor/xxx` | `refactor/database` |

### 6.4 提交信息规范

```
[类型] 简短描述

示例：
[feat] 添加用户登录功能
[fix] 修复列表页空指针异常
[docs] 更新 API 文档
[refactor] 重构数据库查询逻辑
```

## 7. 常用 Git 命令速查

| 操作 | 命令 |
|:---|:---|
| 查看状态 | `git status` |
| 查看修改内容 | `git diff` |
| 拉取最新代码 | `git pull` |
| 创建并切换到新分支 | `git checkout -b 分支名` |
| 切换分支 | `git checkout 分支名` |
| 暂存文件 | `git add 文件名` 或 `git add .` |
| 提交到本地 | `git commit -m "说明"` |
| 推送到 GitHub | `git push origin 分支名` |
| 查看分支列表 | `git branch` |
| 查看提交历史 | `git log --oneline` |
| 合并分支 | `git merge 分支名` |

## 8. 常见问题与踩坑记录

### 8.1 git 不是可识别的命令

**解决：** 安装 Git 后重启终端。如果仍然不行，将 `C:\Program Files\Git\cmd` 添加到 PATH。

### 8.2 python 不是可识别的命令

**解决：** 重新安装 Python，安装时勾选 "Add Python to PATH"。

### 8.3 推送代码时提示权限不足

**原因：** 还没被添加为仓库协作者

**解决：** 把你的 GitHub 用户名告诉项目负责人。

### 8.4 推送代码时提示输入用户名密码

**原因：** Git 没有记住认证信息

**解决：** 配置 Git 缓存密码：

```powershell
git config --global credential.helper wincred
```

### 8.5 合并冲突

当多人修改了同一个文件的同一行时，Git 会产生冲突。

**解决：**
1. `git status` 找到冲突文件
2. 打开文件，找到 `<<<<<<<`、`=======`、`>>>>>>>` 标记
3. 手动保留需要的代码，删除标记
4. 保存文件，执行 `git add .` → `git commit`
