请帮我完成开发环境配置，加入团队的两个 Python 项目（107 和 余庆杯）进行协作开发。以下是步骤：

【步骤 1】检查操作系统版本
确认我的操作系统是 Windows。

【步骤 2】检查并安装 Git
检查是否已安装 Git（查看 C:\Program Files\Git 是否存在）。
如果未安装，用 winget 安装：
    winget install Git.Git --accept-source-agreements --accept-package-agreements
安装后验证：git --version

【步骤 3】检查并安装 Python 3.x
检查是否已安装 Python（查看 python --version）。
如果未安装，引导我从 https://www.python.org/downloads/ 下载安装。
提醒我安装时务必勾选 "Add Python to PATH"。

【步骤 4】配置 Git 用户信息
提示我输入我的 GitHub 用户名和邮箱，然后帮我执行：
    git config --global user.name "我提供的用户名"
    git config --global user.email "我提供的邮箱"

【步骤 5】克隆项目仓库
先确认我要克隆到哪个目录，然后执行：
    git clone https://github.com/AAAtrucklrx/107.git
    git clone https://github.com/AAAtrucklrx/yuqingbei.git

【步骤 6】配置 Python 虚拟环境
进入项目目录，帮我创建并激活虚拟环境：
    cd 项目目录
    python -m venv venv
    venv\Scripts\activate

【步骤 7】提醒事项
提醒我：
1. 把 GitHub 用户名告诉项目负责人，让他把我加为仓库协作者
2. 每次开发前要先用 git pull 拉取最新代码
3. 修改代码后要创建新分支再提交，不要直接在 main 分支上修改
4. 虚拟环境激活后终端前面会出现 (venv) 字样

注意：
- 所有内容用中文输出和解释
- 每一步做完后问我是否继续下一步
- 如果某个工具已安装，跳过安装步骤直接验证
