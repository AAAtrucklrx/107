## 1. 六维契约

### Goal（目标）
把「小蜗」完整部署到本服务器并验证可访问：FastAPI Web（构建后的 SPA 同源托管）+ 独立审核 worker + Streamlit 回退入口，LLM/知识库/评课库全部可用，`GET /api/v1/health/live` 与 `/ready` 通过，浏览器可完成一次 demo 登录问答。

### Boundary（边界）
- 改动范围：`.env`（补 Linux 适配与运行模式）、新建 `deploy/server/*` 管理脚本与日志、`docs/部署规格与记录_2026-09-01.md`。**不修改任何已跟踪源码文件**，不提交 git。
- 数据资产（database/、data/、knowledge/chroma_db/、scripts/data/young_personal/）只读复用，不重建、不迁移。
- 不部署联网 sidecar（SearXNG/Crawl4AI）；不启用 CAS；不占用 80/443（宿主未知服务占用）。

### Acceptance criteria（验收）
1. `.venv` 内可导入 fastapi/chromadb/streamlit/langgraph/onnxruntime；`init_check.py` 通过（知识库向量数 >0 且检索命中）。
2. `frontend/dist/` 构建成功；FastAPI 同源托管 SPA（`GET /` 返回 index.html）。
3. 服务常驻：uvicorn(8000) + worker + streamlit(8502) 由 `deploy/server/` 脚本拉起，健康检查 live/ready 通过，`/api/v1/config/public` 显示 `competition/demo`。
4. 一条真实问答（demo 身份 PB25111691）返回回答；来源标识正确。
5. 全量验证基线：pytest tests/web 通过；verify_tools/test_fixes/verify_nodes 与旧基线一致（LLM 依赖项按授权运行）。
6. 重启脚本可重复执行（stop 干净、start 幂等）。

### Failure modes（失败模式与正确行为）
| 情形 | 正确行为 |
|---|---|
| LLM 平台断连 | 熔断 + 降级路由（代码既有），服务不崩溃，如实返回降级提示 |
| reranker 模型缺失/下载失败 | 自动禁用精排，回退 RRF 原始顺序（降级不报错），记录说明 |
| YOUNG_TOKEN 失效 | 活动功能自动回退本地快照，接口如实标注来源 |
| 端口被占/进程残留 | 启动脚本先杀残留 PID 再拉起；日志可查 |
| 沙箱重启 | 手动 `./start_all.sh` 一键拉起（无 systemd 自愈能力，已与用户确认接受） |
| GitHub 不通 | 部署不使用 git 拉取；npm/pip 全走 registry/PyPI（已实测可达） |

### Priorities（优先级）
正确性 > 完整性：先让核心问答 + demo 工作区可访问，再补 reranker 精排与全量验证；联网 sidecar 明确后置。

### Non-goals（非目标）
- 不部署联网 sidecar、不启用真实 CAS、不申请出校/域名、不做 production 数据发布能力。
- 不重爬评课库、不重建向量库、不重新抓 young 快照。
- 不在沙箱内配置宿主 systemd/nginx（只读区，用户已确认改由 nohup 脚本托管）。

## 5. 部署调优记录（2026-09-01 实测）

- **LLM 平台时延（已更正）**：初测 16s TTFB 系平台故障期数据（用户反馈：平台曾崩溃，现走本机转发）。复测：短问答 TTFB **0.27~0.37s**；但生成耗时与输出长度绑定——4096-token 完整回答实测 **32.4s**（finish=stop，6091 字符）。因此 Web 默认预算 18s/20s 下长答案仍会超时 → 保留 `XIAOWO_GENERATION_TIMEOUT_SECONDS=60`、`XIAOWO_RUN_TIMEOUT_SECONDS=70`（理由更正为"长生成耗时"，非 TTFB）。
- **LLM 客户端超时上限（待用户拍板）**：`config.py` LLM_CONFIG `timeout=30s`（httpx 级），超过 ~4000 字符的答案会先撞客户端 30s 超时（重试 1 次）。如需完整支撑 4096-token 长答案，建议 `timeout` 提到 60s（属代码改动，未擅动）。
- **向量库降级**：现有 chroma 为 768 维（text2vec 时代构建），API embedding qwen3-embedding 为 4096 维 → 按既有设计降级 BM25 关键词检索（接手文档记录的已知行为）。可选后续：用 qwen3-embedding 重建向量库（属数据资产变更，未擅自执行）。
- **锁文件缺口**：requirements.lock.txt 缺 fastapi/pytest（VM pip freeze 遗漏），已补装 fastapi 0.141.1 + pytest；其余 163 包按 lock 安装成功（含 torch 2.13 CUDA 系 ~3GB）。
- **沙箱适配**：/root 与 /etc 只读 → venv 用 `--without-pip`+get-pip；npm 缓存指向工作区 `.npm-cache`；日志全部落 `deploy/server/logs/`。
