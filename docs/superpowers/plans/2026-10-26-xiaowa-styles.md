# 小蛙助手双风格实施计划

**Goal:** 将用户可见品牌改为小蛙助手，默认奶蛙黄，提供科大蓝风格，并采用网上真实大笑动图。

**Architecture:** 沿用已验证的 React / Capacitor 和 FastAPI API。新增独立 AppearanceProvider 管理视觉风格，与 SessionProvider 的浅深色模式正交；不复制两套应用。品牌、首页、按钮、导航与登录页共用语义 tokens。

**Tech Stack:** React 19、TypeScript、Vite、Radix、Capacitor 7。

**Spec:** 当前用户“奶蛙主题、小蛙助手、黄色或科大/奶蛙两版、评估新栈、网上大笑素材”消息。此前“直接开始实施”继续有效。

## 约束
- 用户可见改名；包 ID、原生插件、API、存储键和会话链路保持兼容。
- 不修改线上服务器、问答/工具逻辑；不提交环境或私密文件，不自提交。
- 奶蛙黄/科大蓝都支持浅深色、手机/平板/桌面、44px 触控与可读对比度。
- 原版动图本地打包，来源如实记录；减少动态效果使用静态 fallback。

## 验证重点
- 风格切换后刷新/重开保持选择，存储不可用仍能切换。
- 切换展示层不卸载当前会话，不触发额外 API，不丢草稿。
- 科大风格不展示奶蛙陪伴；奶蛙风格不遮挡输入与导航。
- 原始 GIF 加载失败与 reduced-motion 静态降级。
- Android 应用名称/图标一致，APK 仍小于 25MB。
