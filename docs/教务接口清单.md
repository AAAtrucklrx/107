## 一、核心数据接口(JSON,可直接用)

| 接口 | 返回要点 |
|---|---|
| `GET /for-std/grade/sheet/getSemesters` | 学期列表:`id, nameZh, nameEn, schoolYear, current` |
| `GET /for-std/grade/sheet/getGradeList?trainTypeId=1&semesterIds={ids}` | 成绩:`overview(学分/GPA/加权分), semesters[].scores[](courseNameCh/score/credits/gp/passed), stdGradeRank(档案)` |
| `GET /for-std/grade/sheet/getGradeSheetTypes` | 成绩单类型(打印用):`nameZh, code, enabled, bizTypeIds...` |
| `GET /for-std/course-table/get-data?bizTypeId=2&semesterId={semId}&dataId={dataId}` | 课表:`lessons[](course/credits/teacherAssignmentList/openDepartment/scheduleText/scheduleGroupStr)` |
| `GET /for-std/course-table/semester/{semId}/print-data/{dataId}?weekIndex={n}` | 按周课表(打印格式):`studentTableVm` |
| `GET /for-std/program/root-module-json/{programId}` | 个人方案树:`children(递归), planCourses[](course/readableTerms/compulsory/credits), major` |
| `GET /for-std/sport-grade/list` | **体育成绩**:`schoolYear, score, state, appraisingReachStandard(达标), updateDate` |
| `GET /for-std/startup-plan-defense/available-batches` | 创业计划批次 |
| `GET /for-std/exam-arrange/info/{dataId}` | **个人考试安排**(2026-09-03 实测响应为 JSON/HTML 表格,学期初可能无数据;#exams 表字段:课堂号/考试类型/课程名称/日期时间/考场/教学楼/校区/说明) |
| `GET /home/get-current-teach-week` | **官方当前教学周**(2026-09-03 实测):`{currentSemester:"2026年秋季学期", weekIndex:1, dayIndex:-4(负数=未开课), isInSemester:true}` |
| `GET /for-std/course-table/datum` (POST `{"lessonIds":[...]}`) | **按周课表全量**(533KB):`result.lessonList[]`(每门教学班完整信息:courseName/teachers/schedule/周次);⚠️ 响应大,勿频繁调 |
| `GET /for-std/lesson-search/semester/{semId}/search/{dataId}` | **全校开课查询**(240KB):全学期教学班列表(code 带班号/nameZh/courseName/teacherAssignmentList/scheduleText/openDepartment);搜索参数名未公开,过滤在调用侧做 |
| `GET /ws/for-std/course-select/open-turns` | 选课轮次开放公告(含专项通知) |
| `GET /for-std/course-adjustment-apply/search` | 个性化选课与放弃修读申请记录(status/applyDate/verifyDate) |
| `GET /ws/major-select/data/departments` / `/ws/select-department/departments/getAllByIsCollege` | 院系/专业列表(静态) |

> ⚠️ **重要实测结论(2026-09-03)**:`/for-std/program-search/root-module-json/{pid}`(全校查询树)**不含"要求通过子模块"型分组的课程**(如英语通修——节点为空壳,仅有 type/统计键);完整树只在 **`/for-std/program/root-module-json/{pid}`(学生本人方案)**,对非本人方案返回 1050B 空壳。全校级完整数据无法批量爬取,已用本人方案数据修复 demo fixture(见 scripts/tmp_fix_3011.py / tmp_fix_fixture.py)。
| `GET /for-std/exchange-out-info/search` / `oversea-research-defense/search` / `oversea-research-topic/search` / `program-search/search` / `thesis-topic/search` | 各模块分页搜索:`data, _page_, _sorts_` |
| `GET /for-std/exchange-credit-apply/check-date` | 学分认定日期开关:`result, switchModel` |
