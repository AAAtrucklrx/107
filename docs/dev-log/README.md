# 开发日志（dev-log）

本目录记录每次修复/开发任务的可回溯信息，供后续审查区分「重复工作」与「维护漂移」。

## 记录约定

每个任务一篇 Markdown 文件，命名：`YYYY-MM-DD-<finding-id或任务名>.md`

必需字段：

- **目标**：关联的 finding id（如 `silent-fallback-fabricated-data`）或任务描述
- **改动文件**：本次任务修改的全部文件清单
- **验证**：运行的验证命令与关键输出摘要（含通过/失败结论）
- **遗留问题**：未解决或需后续跟进的事项

## 审查方法

`git log --oneline` + 本目录记录交叉核对：某文件的改动应能追溯到对应记录中的
目标、验证与遗留问题。若改动无记录，即为维护漂移，需补充说明。
