# 评课社区月度全量重爬 — Spec（APPROVED · 2026-09-02 用户定案 A/每月/独立循环）

## 六维契约

- **Goal**：每月自动执行一次现有评课库全量重爬 SOP（`scripts/refresh_course_db.py`），让 `data/course_data.db` 与 icourse.club 同步，全程无需人工介入。
- **Boundary**：新增 `deploy/server/icourse_refresh_loop.sh`（独立 setsid nohup 后台循环）+ 接入 `start_all/stop_all.sh`；**零改动** `crawl_icourse.py` / `refresh_course_db.py` / `build_course_db.py` / `check_course_db.py`；不新增增量逻辑；不爬 pi-review.com；不做内容分析。
- **Acceptance**：① 循环独立运行（pidfile `run/icourse_loop.pid`），启停随 start/stop 联动；② 每月 1 日 02:00（可 `ICOURSE_DAY`/`ICOURSE_HOUR` 调）自动执行 refresh SOP；执行写 `logs/icourse_refresh.log`；③ 重复触发防护（月度 state 记录，月内不重跑）；④ 失败：重试 1 次（间隔 1h）仍败 → 记录告警、保留旧库、下月再试；⑤ `--dry-run`/`--check-only` 透传可用（手动入口 `deploy/server/refresh_icourse_now.sh [--dry-run|--check-only]`）。
- **Failure modes**：站点不可达/CF 403-429（SOP 内指数退避+断点续爬）→ 本月放弃+日志；磁盘 <3G → 前置拦截不跑；与我方看护并发（凌晨低峰，独立进程）；进程被杀 → 下轮循环重新探测补跑。
- **Priorities**：旧库安全（SOP 自带 staging/校验语义，失败不覆盖）> 按期自动 > 数据完整 > 速度。
- **Non-goals**：不增量、不进审核库（review.db）、不采集点评者身份、不缩短 SOP 原有耗时、不做月度以外的额外校准。
